# Space Exploration Quiz

## Overview
The Space Exploration Quiz is a fun and interactive web-based quiz that tests your knowledge about space exploration. It features a series of 10 questions, a progress bar, and a score counter, providing immediate feedback on your answers with colorful animations. At the end of the quiz, you'll see a results screen with an emoji reaction based on your performance.

## Features
- **10 Questions**: A diverse set of questions related to space exploration.
- **Progress Bar**: Visual representation of your progress through the quiz.
- **Score Counter**: Keeps track of your correct answers in real-time.
- **Animated Feedback**: 
  - Green highlight for correct answers.
  - Red shake animation for incorrect answers.
- **Results Screen**: Displays your score with an emoji reaction at the end of the quiz.
- **Responsive Design**: Centered layout in a narrow column, optimized for various screen sizes.
- **Accessibility**: Designed with accessibility in mind, ensuring all users can enjoy the quiz.

## Running the Quiz
To run the Space Exploration Quiz, simply open the `index.html` file in your web browser. There is no need for a server or additional dependencies.

## Design Considerations
- The quiz is styled using a polished, sans-serif font with a body size of 14–16px.
- It respects the user's color scheme preferences (light or dark mode).
- Accessibility features are integrated to ensure a smooth experience for all users.
