# Space Exploration Quiz

Welcome to the Space Exploration Quiz! This interactive quiz will test your knowledge about space and related topics. 

## Project Structure

The project consists of the following files:

- **index.html**: The main HTML file that contains the structure of the quiz application, including the quiz questions, progress bar, score counter, and results screen.
- **styles.css**: The stylesheet that provides a polished look to the quiz application, featuring a sans-serif font, responsive text size, and styles for the progress bar and feedback animations.
- **script.js**: The JavaScript file that contains the logic for the quiz, including tracking the user's score, updating the progress bar, and displaying animated feedback for correct and incorrect answers.

## How to Use

1. **Open the Quiz**: Open the `index.html` file in your web browser. You can do this by double-clicking the file or dragging it into your browser window.
2. **Take the Quiz**: Read each question carefully and select your answer. The quiz will provide immediate feedback on whether your answer was correct or incorrect.
3. **Track Your Progress**: A progress bar will indicate how far along you are in the quiz, and your score will be displayed as you answer questions.
4. **View Results**: At the end of the quiz, you will see your score along with an emoji reaction based on your performance.

## Features

- Animated feedback for correct (green) and incorrect (red shake) answers.
- A progress bar to visualize your progress through the quiz.
- A score counter that updates in real-time.
- Responsive design that adapts to light and dark modes based on your system preferences.
